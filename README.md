# Estoque-de-Mercado-pandas
Um pequeno mercado precisa decidir quantos produtos comprar para a próxima semana.Se comprar demais,sobra mercadoria;se comprar de menos,perde vendas. então esse projeto e criado para controlar o estoque de um mercado para que o mercado não tenha prejuizo com mercadorias em excesso,ou fique com pouca mercadoria.
