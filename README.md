# Estoque-de-Mercado-pandas
Integrates do grupo:Djeuan,Leticia Ribeiro,Hevilly,e Adriano.
Um pequeno mercado precisa decidir quantos produtos comprar para a próxima semana.Se comprar demais sobra mercadoria se comprar de menos perde vendas. Então esse projeto foi criado para controlar o estoque de um mercado para que o mercado não tenha prejuizo como ruptura e excesso de estoque.
Bibliotecas Utilizadas: Pandas NumPy e Matplotlib.
